Testing / exploring options to improve the wifi range on devices.

The built in Wifi antenna isn't very good with long range and is easily blocked (capacaity reduced) just by rotating the device so that the creen and battery block the signal. 

I tested a micro sized TP link usb device with some gain but not enough to be worthwhile and have ordered a few more USB devices to test with.

I know that the board can be modified to add an external antenna, but would prefer to be able to do this without that manual step of physically modifyin an Pi Board.
