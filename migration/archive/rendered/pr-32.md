This is basically an install/upgrade script that will detect if the process is still set to owned by root and will change it over to run as judge. This has some advantages when performing edits in the field (WinSCP or on-device edits) and not all the commands need to run sudo. It then gets the latest release info from GitHub and checks if there is a new version. If there is a newer version, it downloads all the available assets (now includes judge.jar and figures.zip) and extracts them to the appropriate places and restarts the services.
