It's not often, but sometimes as judge assumes the pilot is flying a certain direction and starts the Judge page. If the pilot then tells them they are flying the other direction, the judge has to exit completely to re-select the direction. 

Having an option to flip the direction will save having to lose that time. 
**Allow this only on the first figure (before judging actually begins)**

Perhaps this can be an option in the bottom left to "Change Direction" which then a dialog is displayed with the B or C options available. These can be quick click to change buttons to return right back to the Judge page.
